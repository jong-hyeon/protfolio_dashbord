# 넓은 반응형 포트폴리오 대시보드 설계

## 목표

현재의 자산 추가·목록·총 평가금액 기능은 유지하면서, 큰 데스크톱 화면에서 여유롭고 읽기 쉬운 2단 대시보드로 개선한다. 모바일에서는 모든 내용을 한 열로 자연스럽게 쌓는다.

## 레이아웃

- 전체 컨테이너는 `max-w-screen-2xl`과 반응형 좌우 패딩을 사용한다.
- 헤더는 제목·설명·로그아웃을 넓은 가로 공간에 배치하며, 좁은 화면에서는 세로로 전환한다.
- 총 평가금액 카드는 헤더 아래 전폭으로 두고, 숫자와 보조 설명의 크기를 키운다.
- 데스크톱(`lg` 이상) 본문은 12열 grid를 사용한다.
  - 자산 추가 폼: 4열
  - 자산 목록: 8열
- 모바일과 태블릿에서는 요약 → 자산 추가 → 자산 목록 순서의 한 열로 표시한다.

## 컴포넌트 변경

- `DashboardPage`: 최대 너비, 헤더 높이, 반응형 패딩을 확장한다.
- `AssetsDashboard`: 2단 grid와 섹션 단위를 담당한다.
- `PortfolioSummary`: 더 큰 평가금액 타이포그래피와 카드 여백을 적용한다.
- `AssetForm`: 데스크톱 단일 열 패널, 넉넉한 입력 필드·버튼 높이, 모바일 유지 레이아웃을 적용한다.
- `AssetTable`: 목록 카드 안에 배치하고 작은 화면에서는 가로 스크롤 컨테이너로 감싼다.

## 반응형 규칙

- 기본: 1열, 최소 16px 여백, 표 가로 스크롤 허용
- `sm`: 24px 여백, 폼의 숫자 입력 2열 유지
- `lg`: 32px 이상 여백, 4:8 비율의 2단 grid, 헤더 가로 정렬
- `2xl`: 화면 전체 폭을 활용하되 콘텐츠는 `max-w-screen-2xl` 안에 제한

## 접근성 및 품질

- 표의 의미론적 구조와 폼 label 연결을 유지한다.
- 모바일 가로 스크롤 영역에는 시각적으로 알아볼 수 있는 카드 경계를 둔다.
- 기존 자산 생성·검증·계산 동작은 변경하지 않는다.
- 변경 후 단위 테스트, lint, production build를 실행한다.

## 완료 기준

- 1440px 이상 화면에서 요약·폼·목록이 작게 뭉치지 않고 넓은 2단으로 보인다.
- 1024px 미만 화면에서 내용이 한 열로 전환되고 가로 잘림이 없다.
- 표의 모든 열은 작은 화면에서도 스크롤로 확인할 수 있다.
- 기존 회원가입, 로그인, 자산 추가 테스트가 통과한다.
